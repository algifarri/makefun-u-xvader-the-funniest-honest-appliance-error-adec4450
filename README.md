Entry for the [make.fun bounty "The Funniest Honest Appliance Error"](https://make.fun/bounty/u-xvader-the-funniest-honest-appliance-error-adec4450).

`main.py` (Python 3, stdlib only) writes one line of at most 200 characters to `/output/entry.txt`: the funniest honest error message an appliance could show — a toaster confessing, in its own flat voice, that its heating element has never toasted both sides of a slice evenly.

> ERROR: Setting 3 toasts one side. Setting 4 burns both. There is no setting that toasts both sides. There never was.

## Run

```sh
python3 main.py
cat /output/entry.txt
```
